# My Travel Archive v0.1

아이폰 Safari에서 사용할 수 있는 로컬 우선 여행 기록 PWA입니다.

## 배포

이 폴더의 **내용물 전체**(`index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `assets/`, `vendor/`)를 GitHub 저장소 `main` 브랜치의 최상위(root)에 업로드합니다. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

주소: `https://<GitHub사용자명>.github.io/<저장소명>/`

## 기능

- 여행 앨범 추가/수정/삭제, 영문 여행지 + 한글 제목, 기간/국가/도시/총평
- IndexedDB 로컬 저장, 사진 여러 장 등록, 감상용 JPEG 2000px 및 썸네일 400px 생성
- 가능한 경우 촬영일 자동 분류, 날짜 수동 변경, 날짜별 일기/기분/장소 링크
- 대표 사진 직접 선택, 즐겨찾기, 검정 배경 전체화면 사진 뷰어 및 스와이프
- 연도별 타임라인, 방문 국가 목록, 여행 통계
- 여행별/전체 ZIP 백업, 기존 데이터 보존 방식 ZIP 복원
- PWA 홈 화면 추가 및 기본 오프라인 앱 실행

## 중요 제한 사항

- 사진은 GitHub가 아닌 **현재 기기 IndexedDB**에 저장됩니다. 앱 삭제/브라우저 데이터 삭제/기기 고장 시 손실 위험이 있습니다. **사진 등록 후 반드시 여행별 ZIP 백업을 다운로드하여 별도 보관**하세요.
- ZIP 백업을 생성했다는 알림은 파일 앱에 저장 완료를 보장하지 않습니다. 파일 앱에서 확인하고 다른 위치에도 복사하세요.
- 수천 장을 한꺼번에 가져오거나 수 GB 전체 ZIP을 생성하면 iPhone Safari에서 메모리·저장 한도 문제로 실패할 수 있습니다. 여행별로 나눠 등록/백업하고, 실제 기기에서 단계별 검증하세요.
- 촬영일은 파일 헤더에서 제한적으로 추출하므로 HEIC/일부 사진에서 날짜가 비어 있을 수 있습니다. 해당 사진은 '날짜 미지정'으로 이동합니다.
- HEIC 파일 지원은 사용 중인 iOS/Safari 이미지 디코딩 기능에 따릅니다.
- 사진 압축본은 원본 대체물이 아닙니다. 원본은 사진 앱/별도 저장소에 보관하세요.
- 백업 복원은 기존 동일 ID를 건너뛰는 추가 방식입니다. 기존 기록을 덮어쓰지 않습니다. 복원 중 오류가 나면 일부 항목이 들어왔을 수 있습니다.
- 세계지도 색칠 및 클라우드 동기화는 미구현입니다. 현재는 방문 국가 목록만 표시됩니다.
- GitHub Pages는 공개 사이트입니다. 앱 코드만 배포하고 **개인 사진·일기·백업 ZIP은 저장소에 올리지 마세요**.

## 업데이트 주의

기존 데이터를 보호하려면 IndexedDB 데이터베이스 이름과 저장소 구조를 함부로 바꾸지 마세요. 업데이트 전 ZIP 백업을 만드세요.
